# 🎄 Advent of Code

My solutions to [Advent of Code](https://adventofcode.com/) challenges, implemented in **Python** and **Go**.

## About Advent of Code

Advent of Code is an annual set of Christmas-themed programming puzzles created by [Eric Wastl](http://was.tl/). Each December, a new puzzle is released daily from December 1st to December 25th. The puzzles cover a variety of skill sets and can be solved in any programming language.

## Languages

- 🐍 **Python** - Clean, readable solutions focusing on algorithm clarity
- 🔷 **Go** - Efficient, concurrent solutions leveraging Go's strengths

## Running Solutions

### Python
```bash
cd 2024/day01/python
python solution.py
```

### Go
```bash
cd 2024/day01/go
go run solution.go
```

## Setup

### Prerequisites
- Python 3.13.7
- Go 1.25.2

### Getting Started
1. Clone this repository
2. Navigate to the year and day you want to solve
3. Add your puzzle input to `input.txt`
4. Run the solution in your preferred language

## Notes

- Each day's puzzle has two parts. Solutions aim to solve both parts.
- Input files are not committed to this repository (they're unique per user).
- Solutions prioritize readability and learning over performance (unless specified).
